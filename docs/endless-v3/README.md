# Endless 2.0 · 第一阶段（生成器 v3）

本分支从 `561685c` 设计稿开始，运行基线为已发布 `9a60a7d`，不含本地音乐提交历史。新世界默认 v3；v1/v2 继续使用原生成器、存档键、未访问区域及旧重试规则。第一阶段包含组合生成和冷快照回访，不包含设计稿的第二、三阶段。

## 已实现的体验

普通区块可以真正为空，也可以包含无恒星的流浪行星、孤星、1/2/3/4 行星单星系、双星、2～5 颗碎石或三日系统。原三日、星云地标继续共用生成、导航、发现、背景坐标。没有新增天体类型、伤害、站点、虫洞、主线关卡或音乐。

连续六块尺度的密度场影响空白概率，也只作为现有背景的密度输入。组成、布局和材质分别使用标记随机子流；初始描述不读取镜头、加载顺序或玩家历史。完整碰撞圆离块边至少 80，成员间净距至少 40；起点及邻块保留 600 净空。运行之后天体仍由真实受力、惯性与碰撞决定位置。

32 Seed × 16 × 16 = 8,192 块的实际样本见 [distribution.json](distribution.json)。排除强制地标后的 8,160 个候选：空旷 2,589、流浪 742、孤星 798、小型单星 1,744、多行星 834、双星 629、碎石 653、三日 171。实际有实体的对应数量也单列，不能把两次起点排除后的空块当作流浪/孤星实体。样本最小净边距 80.1566、最小成员净距 40.5052；91 次重叠碎石成员被移除，2 次起点排除。每个布局只构造一次，冲突时有界减少成员；没有反复抽到同一中心的后备模板。

连续空白长度 1/2/3/4 块分别出现 909/254/141/81 段，最长 11 块（只统计该 16 块宽样本的行，不声称全宇宙上限）。留白仍有极长尾部，是否过久需要真人试玩；不会根据等待时间强制在船前刷奖励。

## 初态与物理边界

所有初速度用现有 `bodyGravity` 与 `fieldAcceleration` 的实际软化、范围衰减和加速度计算。双星用两颗星的实际加速度比例确定共同旋转中心。轨道没有脚本、回位或额外校正。

| 配方 | 当前配置与相对 v2 的变化 |
|---|---|
| 单星及行星系统 | 恒星半径 45～70（有行星时 45～65），强度 1,200,000；范围由 v2 的 720 扩至 1,600，软化 100 |
| 1～4 行星 | 半径 18～25；半径层级 180/290/400/510，整体尺度 0.92～1.04，各自初相位；自然引力强度 500、范围 150、软化 40。v2 是强度 90,000/范围 400：这是为分层多体初态选择的较弱局部配置，不宣称引力手感相同 |
| 流浪行星 | 半径 25～43，强度 90,000、范围 400、软化 40；初始漂移分量来自 3～8 的采样，随后真实积分 |
| 双星 | 两颗半径 43～57 的真实 star；强度 900,000 和 650,000～1,150,000，范围 950，间距 260～350 |
| 三日 | 复用半径 48、系统半径 180、强度 1,000,000、范围 750、软化 95 的已验证构型，随机整体方向 |
| 碎石 | 半径 10～19、自然强度 300、范围 100；短弯带或散团，重叠成员按稳定顺序移除 |

节点对所有家族仍有实际作用，自然引力仍影响方舟，双星彼此施力。全局速度 240、通用力律、节点移动和能力、碰撞、镜头均未调整。星环只有装饰。

每个启用家族在 Seed 7、424242、20261017 下运行 120 秒；双星和 3/4 行星分别进一步运行 600 秒。使用真实 CCD、原固定步，检查有限数值、碰撞、预算、速度饱和和逃逸。多行星径向距离限制在初值的 0.98～1.02 内；双星间距在 0.999～1.001 内。原始 33 组记录见 [stability.json](stability.json)：v2 行星比值为 1.000000～1.000175，v3 为 0.996852～1.003565，最高速度分别 53.19/71.31。2% 阈值给代表样本留出约五倍漂移余量，继续检测逃逸与相撞风险。范围 1,100 的早期四行星候选曾出现约 6.64 倍半径逃逸，已拒绝并调整 v3 恒星配置；没有改通用物理来放行。

这些是无外界干预的代表初态，不保证任意邻星扰动、玩家操作或无限时长都保持轨道。普通天体碰撞继续可能吸收、摧毁或按已有配置合并。

## 冷快照与保存

v3 使用独立 IndexedDB 数据库 `the-last-ark.exploration.v3`，不覆盖 `the-last-ark.exploration.v1` 的原文字。生成器版本 3、清单格式 3、Universe 容器版本 1 分开校验。每次新远征有独立 ID；相同 Seed 的新远征也不共享改动。

卸载时保存每个来源块的完整实际快照，包含位置、速度、稳定化分量、半径/合并质量和被删除成员。空数组也是有效墓碑，不能重新生成已清空的块。当前位置索引能从实体的新位置查回来源块，并一次载入其伙伴；无需先回出生块。

读取期间固定步冻结，画面保留当前状态；不会先显示初态再跳回旧对象。写入事务成功才释放唯一活跃快照。热缓存仍最多 32 块，加载最多 54 块、活跃最多 325 体。冷读取若超过这些预算，暂停并保留现场，不丢弃引力源。预载保持船和两节点的三个 3×3 邻域：新生成圆盘到新增邻域内边至少 80，加上最远 1,600 的源范围，正常固定步在切块前有至少 528 单位余量；I/O 期间停止积分，因此不会在读取耗时中继续高速前冲。被移动实体以当前位置索引预载，附近的来源块会保留。`spawnPending` 只保留作旧状态重叠兜底。

K 将活跃、热缓存、冷记录与清单放进同一保存代次的原子事务；另保留最后一次成功 K 的冷记录，继续飞行不会改掉它们。L 原子恢复该代次，递增写入租期，拒绝旧窗口/旧异步请求写回；恢复暂停并关闭技能。离线区域冻结，不按现实时间快进。

- **K**：保存当前远征；事务中断保留上一次 K。
- **L**：v3 优先恢复 v3 槽，若从未保存 v3 则可读取旧槽；正在旧世界时优先旧槽。未知格式或损坏会拒读，不覆盖原文或降级重生成。
- **R**：同 Seed、同生成器规则开始新远征，原 K 保留。
- **Shift+R**：v3 页面恢复最近 K 槽；没有 K 时保留当前状态并提示。旧世界仍按原内存检查点规则。
- 主线的 R/Shift+R 不变。刷新后通过 L 回到最后 K；未按 K 的当前活跃区域不承诺跨刷新恢复。

每远征策略预算为 **64 MiB 的 UTF-8 编码记录与清单负载**，包括该远征当前记录和最后 K 的副本；逐记录字节计数字段自身及数据库索引开销不计入负载。记录还带完整性校验，损坏的空数组不能冒充正常的销毁墓碑。它不是 IndexedDB 磁盘占用的精确测量，浏览器索引/对象存储还有开销，实际浏览器配额可能更低。超过策略预算、拒读/拒写、损坏、事务中断或区域 I/O 超过 10 秒时，固定步暂停并保留现场；L 可退回成功保存，R 可开始新远征。旧历史不会被 LRU 偷删。

64 MiB 是明确起始策略，不是已经测出浏览器能提供的最低容量。自动测试用缩小预算覆盖边界和回滚，真实浏览器另验证事务 abort、容量拒绝、租期过期；没有填满用户磁盘。v3 快照接受合并后的有限半径（上限 512），初始生成半径未因此变大。

尚无面向普通玩家的导出/清理按钮。达到浏览器总配额时，普通用户仍需导出/清理界面，或自行清除站点数据后重新开始；后者会丢弃本机记录。当前恢复提示提供 L/R，不声称它解决浏览器整站配额。开发验证只使用独立测试数据库，没有清理用户存档。多个主动新建远征分别占用磁盘，仍受浏览器总配额限制。

## 验证与重现

基线 `npm run check`：43 文件、585 项通过，构建通过。当前完整结果和浏览器性能见本目录原始记录；旧测试通过固定 v2 fixture 继续运行，未删除旧断言。

```powershell
npm run check
npm run dev -- --port 5184 --strictPort
$env:ARK_CDP_PORT='9344'
$env:ARK_URL='http://127.0.0.1:5184/'
node tools/endless-v3-qa.mjs scenes
node tools/endless-v3-qa.mjs flight 3 20261017 220
node tools/endless-v3-perf-batch.mjs
```

浏览器脚本要求预先启动独立、临时资料目录的 CDP 浏览器。正式游戏入口不开放调试全局；`?dev=1&scene=endless&generator=3&seed=20261017&fx=medium` 可复现开发验收，`generator=2` 对比旧世界。

浏览器检查包含真实双键盘同时移动、F/Enter 切换、暂停、H/J、K/L、R，三 Seed 同世界矩形布局、实际 IndexedDB 事务失败后恢复。全套自动输入、鼠标和手柄适配器回归仍在现有测试中。没有真实两人或实体手柄参与，不把自动双输入称为真人合作验收。

连续航行与构图截图分开记录：布局截图使用明确的开发定位；长航线从正常 `(0,0)`、初速 90 出发，仅通过 `cruiseControls` 给既有节点发目标输入，实际积分跨越 12 块。没有瞬移、修改船速或关闭引力。控制器可观察移动障碍并选择外围绕行；不是产品新增自动驾驶。

待人工确认：长留白体验、变弱的系统行星引力是否足够有趣、两人自由操作下的接近/绕行手感、实体手柄、不同机器性能。跨块大型结构、碎石河、异常天体、信号/遗迹/虫洞与永久发现日志均未开始。
