# 危险机制时钟修复 · 2026-10-18

## 行为

- 黑洞的源天体 `nodeInfluence` 统一提供周期（5 秒）和喷射持续时间（0.8 秒）。节点释放、致命束流碰撞、渲染快照以及无伤害的兼容视觉均使用同一脉冲计算；移除原来独立的 12.25 秒危险束流时钟。每轮前 2 秒预警，后 0.75 秒无伤害消散。独立命中仍扣最大船体值的 50%，保留无敌间隔与连续碰撞检测。
- ready / paused 阶段自由节点可以穿过黑洞核心并移动离开，不产生新捕获。已在运行时捕获的节点继续按原规则冻结；恢复后与同一模拟时钟一起推进。
- 黄色节点满足太阳内停留条件时，在引爆当帧创建扩散波；其 25 秒到达出口的传播时间从实际引爆时刻算起。波的原点、初始半径和速度只锁定一次，50 秒不重复发射。自然定时事件与蓝色节点坍缩后的剩余能量事件仍保留原计划。
- 提前引爆会使原来依赖第 50 秒才爆发的飞行路线提前受到冲击波威胁，这是即时引爆的实际游戏结果。未修改关卡路线或天体美术。
