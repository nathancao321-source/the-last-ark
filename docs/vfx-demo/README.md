# 引力视觉实验

独立入口 `/vfx-demo.html`，通过 `npm run dev` 启动。主游戏入口保持不变。

本目录的初始版本是技术基线：复用 Keyboard、FixedClock、applyPlayerIntent、Camera 和 fieldAcceleration，验证只读 VFX、双场矢量叠加、开启/关闭渐变、有限交互事件池、参数调试和 A/B 门控。

`iteration-1.png` 记录早期外观，作为后续比较，不代表美术验收通过。当前转向用户给定 P1–P5 的电影化二维视觉；阶段 A 背景、阶段 B 节点优先，黑洞和中子星仅规划。

控制：WASD / F、方向键 / Enter；技能按一下切换。Space 暂停，R 重置；全屏后 V 对比、B 记录 10 秒性能、Esc 退出。

## 阶段 A：背景

已查看本地 `参考图/P1.jpg` 至 `P5.jpg`。这些图只作为参考，不打包或上传到仓库。P5 的重点是紫蓝色细丝围绕暗空洞、星点亮度及密度不均；P2 的重点是低密度深空留白。实现采用确定性分形噪声、域扭曲、细丝脊线、尘埃衰减和密度相关的星点，另有少量缓存的遥远星系。

一个后台 Worker 生成 1024² 纹理；最多一个正在计算的请求和一个最新待处理请求。纹理与星点使用相同远景视差。高画质用 8×5 单元、80 个三角形对实际背景纹理做二维仿射形变，中档 6×4，低档静态缓存。星点、纹理顶点和明暗来自同一 `sampleDisturbance`；不会写入玩家/物理状态。关闭高级效果回到技术基线。纹理是可重复的有限远景图案，本 Demo 不承担无限世界背景流式生成。

阶段 A 验证：402 项测试通过、构建成功；真实浏览器截图见 `stage-a-dense.png` / `stage-a-sparse.png`。1382×746 画布、每档 10 秒、双场开启：高档密集背景 165 FPS / 绘制 CPU p95 2.4 ms / 119 次提交；中档稀疏背景 165 FPS / p95 2.0 ms / 78 次提交；低档密集背景 165 FPS / p95 1.8 ms / 11 次提交。后台生成约 550 ms。FPS 来自 rAF，CPU 不等于 GPU 完成耗时。三档画质只在本机测过，不能代表所有设备。

## 后续阶段（未实现）
