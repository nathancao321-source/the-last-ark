# 吸积盘结构与动态验收记录

## 实现与边界

主盘、上弯折带、内缘共享黑洞世界中心 (1300, 0)，统一通过现有摄像机变换绘制。captureRadius=100，物质内缘=100.8，外缘=480。内外径共享同一极坐标纹理与模拟时间，角速度随半径的 1.5 次幂衰减：内缘约 65.1°/s，外缘约 6.3°/s。连续热点与低幅度亮度变化均确定性计算，无每帧随机跳变。

黑洞危险核心最后以纯黑遮罩覆盖；此次吸积盘更改未改动喷流伤害、碰撞规则与关卡路线。UI 下载合并后，相应渲染和机制文件与合并前备份相同。

## 与 P1 的实际差异

已具备贴近黑洞的亮内缘、横向金白色盘面、连贯上弯折带与连续差动流动。当前版本仍比 P1 更对称，盘面更偏椭圆环带，P1 左右流体的不规则性与强烈非对称高光尚未完全复现。P1 的前景盘面穿过黑圆下部；当前按危险核心始终可辨的要求保留完整漆黑圆面。不能将此版本描述为与 P1 完全一致。
